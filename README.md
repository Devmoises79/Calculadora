## 🧮 Calculadora Simples em C#
Este projeto é uma calculadora de terminal desenvolvida em C#, que permite ao usuário realizar as quatro operações básicas da matemática: soma, subtração, multiplicação e divisão. Ideal para iniciantes que desejam compreender os fundamentos da linguagem C#.

## 📋 Funcionalidades
Interface de terminal simples e interativa

Operações disponíveis:

- Soma

- Subtração

- Multiplicação

- Divisão (com validação contra divisão por zero)

## 🚀 Como Executar
Certifique-se de ter o .NET SDK instalado em sua máquina.

Execute o programa compilado:

```bash
dotnet run
```

## 📘 Conceitos Abordados
Este projeto foi feito para demonstrar conceitos básicos da linguagem C#:

## ✅ Console.WriteLine() e Console.ReadLine()
- WriteLine() é usado para exibir mensagens no terminal.
- ReadLine() captura a entrada do usuário como string.

## ✅ Conversão de tipos
- Convert.ToInt32() e Convert.ToDouble() são usados para converter a entrada (string) do usuário em números.

## ✅ Estrutura condicional switch
- Utilizada para executar diferentes blocos de código dependendo da escolha do usuário (1 a 4).

## ✅ Operações matemáticas básicas
- Realiza soma (+), subtração (-), multiplicação (*) e divisão (/).

- Verifica se o divisor é zero para evitar erro na divisão.

## ✅ Tipos de dados
int para números inteiros (opção escolhida pelo usuário).

double para números decimais (números usados nas operações).

string implicitamente usada ao ler dados do teclado.

## ✅ Controle de fluxo com return
O uso do return permite encerrar a execução do programa em casos específicos, como:

- Divisão por zero

*Opção inválida no menu
